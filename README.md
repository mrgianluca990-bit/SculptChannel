# Sculpt Channel v0.3 — Variation

## New: VARIATION

VARIATION changes only the resonance-control stage.

### OFF
Broad, analog-style resonance management tied to the four main tone regions.

### ON
A focused dynamic mini-soothe using six narrow, fixed detector bands:

- 200 Hz
- 500 Hz
- 1 kHz
- 3 kHz
- 5 kHz
- 8 kHz

These are NOT static EQ notches. Each band reacts dynamically only when energy in that area protrudes relative to its local envelope.

The detector is stereo-linked.

The four macro knobs still control the amount:
- LOW mainly drives 200 Hz
- MID mainly drives 500 Hz / 1 kHz
- HIGH mainly drives 3 kHz / 5 kHz
- PRESENCE mainly drives 8 kHz
- adjacent regions overlap slightly for smoother behaviour

Compression and saturation remain the same as Sculpt Channel v0.2.
