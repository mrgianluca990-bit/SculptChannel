# Sculpt Channel v0.1

Dynamic analog-style tone conditioner.

Core macro bands:
- LOW — 85 Hz
- MID — 700 Hz
- HIGH — 3.5 kHz
- PRESENCE — 10 kHz

Each macro is bipolar:
- Positive: resonance control -> compression -> saturation -> perceived forwardness
- Negative: stronger resonance control + compression, reduced saturation -> perceived recession

Stereo-linked concept, with separate RES / COMP / SAT activity meters for each band.
